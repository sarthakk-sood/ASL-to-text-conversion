# ASL Neural Dashboard

A real-time American Sign Language (ASL) detection and translation tool. This project uses Google's MediaPipe for sophisticated 3D hand tracking alongside a custom-trained Scikit-Learn Multilayer Perceptron (MLP) Neural Network for classification, providing instant translation of ASL gestures to English text.

## Features

- **Real-Time Detection:** Smooth mapping of 21 3D hand joint coordinates inside the browser via computer vision.
- **Deep MLP Network:** High accuracy classification resolving 26 alphabets + space and delete commands.
- **Neural UI Dashboard:** Built in React with Vite, displaying a target bounding box, active prediction tags, accuracy confidence markers, and dynamic prediction buffers before "locking in" a typed letter.
- **Auto-Correction Engine:** Integrated `TextBlob` in the Django backend cleans up naturally misspelled words generated by fast or overlapping sign transition speeds.
- **Full-Stack Implementation:** Headless Django REST API backend wired to a responsive React JS frontend. 

## Project Structure

- `api/` & `backend/` - Django application serving predictions and autocorrect APIs.
- `frontend/` - React & Vite application for user interaction and webcam control.
- `train_mlp.py` - Builds an optimized Multi-Layer Perceptron using normalized relative hand coordinates.
- `evaluate_test.py` - Verifies accuracy against distinct test datasets.
- `extract_features.py` - Maps local ASL images into deep features via MediaPipe `hand_landmarker`.
- `predict_sentence.py` - Local Python test script for OpenCV webcam interactions.

## Installation

### 1. Python Backend
Create a virtual environment and ensure dependencies are installed:
```bash
python -m venv .venv
# Activate environments
# Windows: .venv\Scripts\Activate.ps1
# Mac/Linux: source .venv/bin/activate

pip install -r requirements.txt
```
*Note: Make sure to download Google's `hand_landmarker.task` file into the root directory before running feature extractions.*

### 2. React Frontend
In a new terminal window, initialize the Vite UI:
```bash
cd frontend
npm install
```

## Running the Application

1. **Start the API Server**
```bash
python manage.py runserver
```

2. **Start the React UI**
```bash
cd frontend
npm run dev
```
Open the provided `localhost` link, click "Start Camera", and begin signing!
